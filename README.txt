Shape Garden / Taman Bentuk
Geometry practice — latest iPad layout

24 interactive questions covering area, perimeter, circles, and compound shapes.
English is the default language. Select IND for Indonesian.

To open on a computer: extract the entire ZIP, then open index.html in a browser.
Keep the assets folder and all CSS/JS files together.
To use on an iPad, open the hosted site or upload the extracted folder to static hosting.

Hosted site:
https://taman-bentuk-geometry-quest.nyaooowzz.chatgpt.site

Answers and apple progress are saved in the browser on each device.
The ZIP contains the app, not any student's saved answers.
